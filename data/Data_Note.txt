RULES
sales_mode: n = int(first 8 hex digits of MD5(InvoiceNo), 16).
  n mod 10 = 0..6 -> Online, 7..9 -> Periodic (one label per cart).
  Online: 12,971 carts (69.99%), 278,740 rows. Periodic: 5,561 carts (30.01%), 119,144 rows.
Store: Online -> store 1; Periodic -> store 2 + (n mod 4). Store list kept in memory.
Master Data attributes: stable(text, k) = MD5 number of text mod k (index into the list
  of values given in the project statement).
  Customer: gender = stable(id, 2); age_group = stable(id + "age", 7);
  occupation = stable(id + "occ", 10); city_category = stable(id + country, 3);
  stay_in_current_city_years = stable(id + "stay", 5); marital_status = stable(id + "mar", 2).
  Product: product_name = longest description; product_category = stable(id + "cat", 10);
  supplier = stable(id, 5) (5 suppliers).
Partitions: 500 rows -> customers 9, products 8.
Periodic groups: periodic sales sorted by time; whole carts; cart goes to group
  (start row x 48) div 119,144; 48 groups of 2,263 to 2,710 rows.
